# 🌊 Морской маршрутный оптимизатор

Веб-приложение для оптимизации маршрутов морских судов с гибридными пропульсивными установками на основе метеоданных и искусственного интеллекта.

## 📋 Возможности

- Построение морского маршрута через акваторию Мирового океана
- Три режима маршрута: **Экономичный**, **Быстрый**, **Безопасный**
- Динамическое распределение: **дизель / паруса / батареи**
- Интеграция с **OpenWeatherMap API**
- Обход опасных зон (штормы, сильный ветер, высокие волны)
- ИИ-рекомендации для судоводителя

## 🛠️ Технологии

- **Backend:** Python 3.14, Flask, Flask-CORS
- **Frontend:** HTML5, CSS3, JavaScript, Leaflet.js
- **Данные:** CSV (порты), GeoJSON (акватория), JSON (кэш сетки)
